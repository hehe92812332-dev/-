# 1년 · 100만 명 사용 시뮬레이션 보고서

실행일 2026-10-27. 같은 코드(규칙 엔진 `src/lib/ledger.ts`, 서버 `src/server/*`)로 두 가지를 확인했습니다.

1. **행동 시뮬레이션** — `scripts/simulate-year.ts`: 회원 100만 명(치료사 3%)의 1년 활동을 1% 표본(1만 명)으로 돌리고 ×100 환산
2. **규모 시험** — `scripts/scale/*`: 1년치 데이터(회원 100만, 질문 92만, 답변 80만, 거래 200만, 평가 35만, 라운지 메시지 300만, 약 2GB)를 실제 PostgreSQL에 넣고 응답 시간·동시 접속·동시 쓰기 측정

가정(조정 가능, `scripts/simulate-year.ts` 상단): 환자의 30%가 1년에 한 번 이상 질문(평균 3건), 멤버십 3.7%, 1:1 질문 12%, 치료사는 하루 18% 확률로 접속해 평균 1.6개 답변, 환자가 고르는 등급은 중·상위에 많음(토파즈 이상 73%).

## 1. 발견한 문제와 조치

| # | 문제 (근거) | 조치 |
|---|---|---|
| 1 | **첫 화면이 60~90초, 78MB** — 모든 질문·회원·평가를 한 번에 내려줌 | 화면별 페이지 API(목록 20건씩, 상세, 치료사, 프로필, 라운지)로 분리, 브라우저는 필요한 만큼만 캐시 |
| 2 | **질문의 48%가 답변 없이 환불** — 치료사의 56%가 원석인데 질문은 중·상위 등급에 몰림 | ① 질문할 때 **'답변이 없으면 자동으로 등급 낮추기'(기본 켜짐)**: 하루마다 한 단계씩 넓히고 차액 즉시 환불 ② 끈 질문은 24시간 뒤 낮추기 제안 알림 ③ 치료사용 **'내가 답변할 수 있는 질문'** 목록 (답변 없는 질문 → 답변 가능자가 적은 질문 순, 3개 이상 답변된 질문 제외) |
| 3 | **1:1 질문의 61%가 무응답 환불** — 치료사가 질문이 온 줄 모름, 48시간이 짧음 | **알림**(1:1 질문 도착·새 답변·채택·팁·심사 결과·입금 등) + 응답 기한 72시간 |
| 4 | **치료사 수익이 묶임** — 연 수익 중앙값 24토큰인데 최소 환전 500토큰, 환전 경험 16% | 최소 환전 **100토큰**으로 |
| 5 | **환자 미사용 잔액 약 110억 원** — 최소 충전 300토큰·멤버십 500토큰 대비 질문 1건 평균 25토큰 | **충전 잔액 환불 신청**(청약철회 기간 이후 미사용 충전분, 수수료 10%) 추가. 충전 단위 자체는 정책 결정 사항으로 유지 → 아래 '남은 과제' 참고 |
| 6 | **원석 라운지 하루 4,500개 메시지가 한 방에** | 등급 라운지를 **주제별 7개 채널**로 나누고 이전 대화 불러오기, 새 글 표시 |
| 7 | **검색이 드문 단어에서 4.4초** (전체 스캔) | 트라이그램(pg_trgm) 인덱스 |
| 8 | **라운지 폴링 1회 200ms** (100만 명 규모에서 3초마다) | 채널별 인덱스 조회로 6ms |
| 9 | **같은 질문에 50명이 동시에 답하면 실패** (직렬화 충돌 재시도 소진) | 바꿀 행을 정해진 순서로 잠그는 방식(READ COMMITTED + FOR UPDATE)으로 변경 → 줄을 서서 처리 |
| 10 | **치료사 서류가 DB에 쌓임** (3만 명 × 서류 3~4장 = 수십 GB) | S3 호환 저장소 연결 (`STORAGE_DRIVER=s3`), 개발용은 DB 그대로 |
| 11 | 서버 메모리가 계속 늘어남 (요청 제한·조회수 기록 미정리) | 만료 항목 주기적 정리 |
| 12 | 단일 서버 프로세스가 약 500 req/s에서 포화 → 동시 200명일 때 일부 응답 14초 | 비회원 조회 응답 짧은 캐시(서버 + CDN), 자체 서버용 멀티 프로세스 실행(`npm run start:cluster`) |
| 13 | 온도·등급·답변 수를 매번 계산 | 미리 계산해 저장 (`users.temperature`, `therapist_profiles.tier`, `posts.answer_count` 등), 블라인드 평가는 공개 시점에 반영 |

## 2. 행동 시뮬레이션 결과 (100만 명 환산, 같은 시드)

| 지표 | 처음 | 정책만 변경 (환전 100·1:1 72시간) | 모든 개선 반영 |
|---|---|---|---|
| **답변 없이 환불된 질문** | 48.4% | 48.0% | **0.6%** |
| **1:1 질문 무응답 환불** | 61.2% | 53.8% | **5.2%** |
| 질문 1건 평균 비용 | 24.9토큰 | 24.6토큰 | 21.7토큰 (자동 낮추기 차액 환불) |
| 치료사 연 수익 중앙값 / 상위 10% | 24 / 682토큰 | 28 / 672토큰 | **65 / 1,634토큰** |
| 한 번이라도 환전한 치료사 | 16.3% | 39.0% | 44.0% |
| 치료사 환전 총액 | 3.1억 원 | 5.3억 원 | **12.9억 원** |
| 플랫폼 수수료 수입 (채택·팁) | 1.25억 원 | 1.26억 원 | **3.0억 원** |
| 만족도 평가를 받은 회원 | 9.3만 명 | 9.1만 명 | 16.9만 명 |
| 연말 환자 미사용 충전 잔액 | 110억 원 | 110억 원 | 101억 원 |

등급별(처음 고른 등급 기준) 무답변 환불 — 개선 후: 원석 0.5%, 진주 0.0%, 오팔 0.1%, 토파즈 0.4%, 자수정 0.2%, 에메랄드 0.4%, 사파이어 0.4%, 루비 0.9%, 다이아몬드 3.3%.

'모든 개선 반영' 열에서 '수익이 있지만 100토큰 미만이라 아직 환전하지 않은 치료사'가 55%로 보이는 것은, 답변이 고르게 퍼져 **소액이라도 수익을 얻은 치료사가 크게 늘었기** 때문입니다(연 1~2회 답변하는 치료사).

## 5. 남은 과제 (정책 결정 필요)

- **미사용 충전 잔액 약 100억 원**: 최소 충전 300토큰·멤버십 월 500토큰은 질문 1건 평균 22~25토큰에 비해 큽니다. 잔액 환불 신청을 추가했지만, 선불 충전금이 이 규모로 쌓이면 전자금융거래법상 선불전자지급수단 관련 의무(등록·충전금 보호 등)가 생길 수 있어 법률 검토가 필요합니다. 최소 충전을 낮추거나 '질문 1건 바로 결제'를 함께 두는 방법도 검토할 만합니다.
- **소액 수익 치료사**: 연 1~2회 답변하는 치료사가 많아 100토큰 미만 수익이 남습니다. 연 1회 자동 정산(예: 연말 10토큰 이상 일괄 지급) 같은 정책을 고려할 수 있습니다.
- 시뮬레이션은 가정에 따라 결과가 달라집니다. 실제 운영 데이터가 쌓이면 가정(접속률·등급 선택 비율 등)을 실측값으로 바꿔 다시 돌려 보세요.
