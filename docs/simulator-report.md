# 동작 보상 시뮬레이터 — 가상 사용자 100만 명 사용 시뮬레이션

`scripts/simulate-users.ts` 로 가상 사용자 1,000,000명이 시뮬레이터를 한 번씩 쓰는 상황을 재현했습니다. 사용자마다 체형·가동성·근력·동작·무게가 다르고, 그 결과를 오류와 불만 유형으로 나눠 집계했습니다. 최종 집계 원본은 [`simulator-report.json`](simulator-report.json)에 있습니다.

## 가상 사용자 구성

| 집단 | 비율 | 특징 | 주로 고르는 동작 |
| --- | --- | --- | --- |
| 체대입시 수험생 | 30% | 파워 66±14, 조절 60±15, 가동성 약간 좋음 | 체대입시 70% · 웨이트 20% · 스포츠 10% |
| 일반 헬스인 | 45% | 파워 45±18, 조절 56±17 | 웨이트 82% · 스포츠 13% · 체대입시 5% |
| 선수 | 15% | 파워 76±12, 조절 70±12 | 스포츠 55% · 웨이트 35% |
| 재활·초보 | 10% | 파워 24±12, 조절 40±15, 가동성 낮고 편차 큼 | 웨이트 85% · 스포츠 15% |

- 키: 남 173.5±6cm, 여 161±5.5cm. 체중은 BMI 분포(15~45)로 생성
- 팔·다리·무릎 높이·몸통·어깨·골반은 같은 키 표준 비율에서 각각 3~6% 범위로 독립적으로 흔들고, 25%는 다리 길이 차이(±0.7cm)를 넣음
- **입력 실수 2.5%**: 키를 인치로, 발 길이를 cm로, 팔 길이 대신 양팔 너비, 체중을 파운드로, 다리·무릎 값 뒤바뀜, 빈칸(NaN), 음수, 0, 다리 길이 대신 가랑이 높이
- 무게: 체중·파워에 맞춰 고르되 5%는 슬라이더 최대, 5%는 최소
- 2%는 체형 하나를 바꿔 다시 계산하는 **민감도 검사**도 함께 실행 (예: 넙다리 8% 길게 → 스쿼트 보상 증가, 팔 6% 길게 → 좌전굴 기록 증가, 체중 15% 증가 → 서전트 감소)

이보다 앞서 개발 단계에서 고친 문제:
- 동적 동작의 지면반력이 체중의 20~300배로 계산됨 → 키프레임과 체공 탄도의 속도 불일치 때문. 착지·이륙 충격량을 운동량에 맞게 분배하도록 바꿔 드롭 착지 2.6~3.3배, 달리기 약 3배로 정상화
- 45° 컷·셔틀런에서 무릎 안쪽 이동이 38cm로 계산됨 → 흔드는 다리까지 측정했기 때문. 디딘 다리만, 발끝 방향 기준 평면에서 측정
- 리버스 런지에서 한 발로 설 때 무게중심이 발 밖에 있었음 → 발을 옮기기 전에 체중을 앞발 위로 옮기는 단계 추가
- 힙 쓰러스트 최고점이 무릎 68°·고관절 과신전 21° → 최고점에서 넙다리가 수평이 되는 몸통 각도를 풀고, 정강이가 수직이 되도록 발 위치 결정
- 기본값 사용자에게 스쿼트마다 "무릎 무너짐 위험"이 뜸 → 조절 능력 60점 기준 외반 각도 재보정
- 3D 화면: 체공 구간에서 지지면 선의 점 개수가 바뀔 때 three.js 가 오류를 냄 → 버퍼를 새로 만들도록 수정

**1차 → 2차 수정**
- 가속 스프린트에서 흔드는 발이 바닥을 뚫음(268건) → 디딘 발보다 낮아지면 무릎·고관절을 더 굽혀 들어 올리도록 함
- 고블릿·오버헤드 스쿼트에서 "평범한 체형인데 위험" → 체중 대비 무거운 덤벨·케틀벨을 들고 있었음. 모든 기구에 **추정 최대 근력 초과 경고**를 추가해 원인을 함께 보여 줌
- 짧은 다리로 벤치프레스를 할 때 발이 바닥에 닿지 않음 → 발판 자동 배치
- 배근력 상위 기록 과대(300kg 이상) → 근력이 체중의 2/3 제곱에 비례하도록 바꿈. 메디신볼 상위 기록(21m 이상) 완화
- 가상 사용자 생성기가 생리적으로 불가능한 값(어깨 굴곡 206°, BMI 7)을 만들던 문제 수정
- 파워가 이미 100인 사용자에게 "파워 +15" 민감도 검사를 해 '변화 없음'으로 잡히던 검사 오류 수정

**2차 → 최종 수정**
- 2차의 '반대로' 증가(285건)는 검사 기준을 '몸통 각'에서 '보상 지수'로 바꾸면서 발목 배측굴곡을 포함했기 때문. 발목 가동성은 쓰는 '자원'이라, 가동성을 줄이면 오히려 줄어드는 게 정상 → 발목 검사는 배측굴곡을 뺀 지수로 판정
- **실제 엔진 버그**: 뒤꿈치가 들리면 지지면이 발볼~발끝으로 줄어드는데 균형 목표를 여전히 발 중앙에 둬서 '무게중심 이탈'이 잘못 나왔음 → 뒤꿈치 들림에 따라 균형 목표를 발볼 앞으로 옮김 (스쿼트·스플릿 공통)

### 남은 항목과 판단

- **정상 입력이 자동 수정됨 0.13%**: 다리+몸통이 키와 맞지 않아 머리·목 길이가 키의 12% 미만이거나 25% 초과가 되는 경우입니다(예: 키 179.5cm, 다리 85cm, 몸통 49cm → 머리·목 46cm). 실제로도 측정이 잘못된 경우라 비례 조정하고, 무엇을 얼마나 바꿨는지 진단 패널에 보여 줍니다.
- **잘못된 입력을 못 잡음 0.016%**: 파운드로 넣었지만 BMI가 40 이하라 비만 체형과 구분되지 않는 경우입니다. BMI 40을 넘으면 "lb로 넣지 않았는지 확인" 안내를 띄웁니다.
- **평범한 체형인데 위험 0.004%**: 발목 가동성 33~35°로 고블릿·오버헤드 스쿼트를 깊게 앉을 때 뒤꿈치가 13° 들리는 경우입니다. 실제로도 나타나는 보상이라 경고를 유지했습니다.
- **반대로 0.002% / 그대로 0.007%**: 고관절 굴곡 한계에 걸린 상태에서 넙다리를 늘리면 깊이 손실 대신 허리 말림으로 보상이 옮겨 가는 경계 사례, 정수로 반올림하는 풀업 횟수, BMI 보정 상한에 걸린 서전트 등입니다.

### 부위별 부상 위험도 계산

7개 부위(허리, 무릎, 발목·아킬레스건, 고관절·골반, 햄스트링, 어깨, 팔꿈치·손목)마다 아래 요인 점수를 더해 0~100으로 냅니다. 30 이상은 주의, 60 이상은 높음입니다.

| 부위 | 주요 요인 |
| --- | --- |
| 허리 | 부하 상태의 허리 굽힘(버트윙크·등 말림), 과신전, 요추 신전 모멘트, 숙인 채 충격 흡수, 최대 근력에 가까운 부하 |
| 무릎 | 무릎 안쪽 무너짐(충격 중이면 가중), 무릎 신전 모멘트, 뒤꿈치 들림(슬개건), 착지 지면반력, 뻣뻣한 착지, 깊은 굴곡에서 무거운 부하, 좌우 근력 차이 |
| 발목·아킬레스건 | 가동범위 끝 사용, 뒤꿈치 들림, 저측굴곡 모멘트, 한 발 지지 충격, 배측굴곡 부족 |
| 고관절·골반 | 굴곡 끝 범위 반복(앞쪽 끼임), 골반 기울기·떨어짐, 신전 모멘트, 다리 길이 차이 |
| 햄스트링 | 유연성 한계 근처까지 늘어남(무릎 굴곡 보정), 고속 달리기 편심 부하, 짧은 햄스트링, 좌우 차이 |
| 어깨 | 굴곡 부족, 어깨 모멘트, 끝 범위 사용, 매달림, 벤치·푸시업 바닥 지점 신장 |
| 팔꿈치·손목 | 손으로 지지하는 체중, 프론트 랙 손목 꺾임, 매달려 당기기, 던지기 릴리스 |

달리기·점프처럼 정상 수행에도 관절 모멘트가 큰 동작은 모멘트 기준선을 2.1배로 높여, 기본 체형이 이유 없이 '높음'으로 나오지 않게 했습니다.

## 5차: 관절 가동범위(ROM) 점검·수정

모든 프레임에서 관절 각도를 해부학적 정상 범위(AAOS·AMA 기준을 약간 넉넉히)와 비교하는 `src/lib/biomech/rom.ts` 를 추가했습니다. 고관절·어깨 회전은 swing-twist 분해로 측정합니다.

| 관절 | 허용 범위 (°) |
| --- | --- |
| 고관절 굴곡/신전 | -30 ~ 140 |
| 고관절 외전/내전 | -30 ~ 50 |
| 고관절 내회전/외회전 | -50 ~ 45 |
| 무릎 | -5 ~ 155 |
| 발목 배측/저측굴곡 | -55 ~ 55 |
| 어깨 굴곡/신전 | -65 ~ 190 |
| 어깨 회전 | -110 ~ 80 |
| 팔꿈치 | -8 ~ 152 |
| 척추 굴곡/신전 · 측굴 · 회전 | -45 ~ 85 · ±40 · ±60 |
| 목 | -60 ~ 50 |

처음 점검(5개 체형 × 36개 동작)에서 51건이 범위를 넘었고, 아래와 같이 고쳐 0건이 되었습니다.

- 다리·팔 역기구학: 무릎·팔꿈치 방향(pole)을 고관절·어깨 회전 한계 안으로 끌어오고, 팔꿈치는 완전 굽힘 150° 이내로 제한
- 동적 동작: 모든 관절 각도를 해부학 범위로 자르고, 지지발 방향·좌우 위치·골반 기울기에 한계를 두며, 발목 배측굴곡이 한계를 넘으면 뒤꿈치를 들게 함
- 불가리안 스플릿 스쿼트: 벤치 높이·거리를 다리 길이에 맞추고, 뒷발 발목·앞쪽 고관절 굴곡이 한계에 닿으면 깊이를 줄임(깊이 손실로 표시)
- 벤치프레스: 어깨 신전이 60°에 닿으면 바가 가슴 위에서 멈춤(팔이 긴 경우), 키 작은 사용자 발판 높이 보정
- 오버헤드·스쿼트: 어깨 굴곡·고관절 굴곡 사용량 상한
- 좌전굴·사이드스텝·컷 동작: 골반 기울기, 보폭, 지지발 위치 보정

가상 사용자 4만 명 재실행 결과 `오류:관절 가동범위 초과` 는 0.168% → **0.003%(1건)**. 남은 1건은 넙다리 길이에 다리 전체 길이(93cm)를 넣은 잘못된 입력입니다. vitest 에 3개 체형(기본·유연·뻣뻣) × 36개 동작 전 프레임 ROM 검사를 추가했습니다(52개 통과).

## 화면 점검

`scripts/ui-check.cjs` 로 36개 동작을 데스크톱(1440×900)에서 하나씩 열고, 진단·수치 탭을 오가며 콘솔 오류와 화면에 찍힌 NaN·undefined를 확인했습니다. 모바일(iPhone 13)에서는 대표 동작 5개의 네 탭에서 가로 스크롤이 생기는지 확인했습니다. 최종 결과 **문제 없음** (부상 위험 패널·3D 위험 부위 표시 추가 후에도 동일).
