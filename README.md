# PT 브릿지 (PT Bridge)

물리치료사와 환자를 잇는 임상 지식 플랫폼.

- **환자 Q&A** — 환자·보호자가 원하는 등급의 물리치료사에게 질문
- **임상 토론** — 치료사 회원 전용 케이스 토론
- **등급제** — 경력(최대 40) + 교육 이수 시간(최대 30) + 근무 기관(최대 30) = 100점 → 루키/프로/엑스퍼트/마스터/레전드
- **토큰 경제** — 현금 충전 → 등급별 비용으로 질문(에스크로) → 채택 시 답변자에게 지급(수수료 차감) → 획득 토큰만 현금 환전

## 실행

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # 프로덕션 빌드
```

## 구조

| 경로 | 설명 |
| --- | --- |
| `src/lib/config.ts` | **정책 값** — 등급 기준, 질문 비용, 토큰 가격·패키지, 수수료, 환전 조건 |
| `src/lib/tier.ts` | 점수·등급 계산 |
| `src/lib/store.tsx` | 데이터 계층과 액션(충전, 질문, 답변, 채택, 환전). 현재 localStorage 데모 |
| `src/lib/seed.ts` | 데모 데이터 |
| `src/app/*` | 페이지 (홈, `/qa`, `/clinical`, `/therapists`, `/tiers`, `/wallet`, `/signup`) |

우측 상단 아바타 메뉴에서 데모 계정(환자/등급별 치료사)을 전환하고, "데모 초기화"로 데이터를 되돌릴 수 있습니다.

## 실서비스 전환 시 해야 할 일

1. **백엔드·DB** — `store.tsx`의 액션을 API 라우트 + DB(예: PostgreSQL/Supabase)로 교체. 토큰 이동은 반드시 서버 트랜잭션으로 처리
2. **인증** — 카카오/네이버 소셜 로그인, 치료사 면허 진위 확인 및 경력·보수교육 증빙 심사
3. **결제** — PG 연동(토스페이먼츠, 포트원 등), 청약철회·환불 처리
4. **환전** — 본인 계좌 인증, 원천징수 신고, 지급 대행
5. **법률 검토** — 선불전자지급수단(전자금융거래법), 의료법(비대면 상담·의료광고 범위), 개인정보·민감정보 처리
