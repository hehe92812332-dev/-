# PT 브릿지 (PT Bridge)

물리치료사와 환자를 잇는 임상 지식 플랫폼.

- **환자 Q&A** — 환자·보호자가 원하는 등급의 물리치료사에게 질문
- **임상 토론** — 치료사 회원 전용 케이스 토론
- **보석 등급제 (1~8등급)** — 경력 · 물리치료학회 인정 교육 시간 · 석/박사 학위를 모두 충족한 가장 높은 등급

  | 등급 | 보석 | 경력 | 학회 인정 교육 | 석·박사 | 질문 비용 |
  | --- | --- | --- | --- | --- | --- |
  | 1 | 다이아몬드 | 15년+ | 500시간+ | 필요 | 50 |
  | 2 | 루비 | 15년+ | 500시간+ | – | 42 |
  | 3 | 사파이어 | 10년+ | 400시간+ | 필요 | 35 |
  | 4 | 에메랄드 | 10년+ | 400시간+ | – | 28 |
  | 5 | 자수정 | 5년+ | 300시간+ | 필요 | 22 |
  | 6 | 토파즈 | 5년+ | 300시간+ | – | 17 |
  | 7 | 오팔 | 3년+ | 200시간+ | 필요 | 13 |
  | 8 | 진주 | 3년+ | 200시간+ | – | 10 |
  | – | 원석 | 8등급 미만 면허 인증 회원 | | | 5 |

  질문 1건 비용은 1:1 지정 할증을 포함해도 **최대 50토큰(5,000원)** 입니다 (`MAX_QUESTION_COST`).
- **토큰 경제** — 현금 충전 → 등급별 비용으로 질문(에스크로) → 채택 시 답변자에게 지급(수수료 차감) → 획득 토큰만 현금 환전

### 참고한 토큰·포인트 결제 서비스 구조

| 기능 | 참고 모델 | 구현 |
| --- | --- | --- |
| 충전/보너스/수익 지갑 분리 | 숨고 캐시·보너스캐시 | 보너스 → 충전 → 수익 순 차감, 보너스는 환불·환전 불가 |
| 미응답 자동 환불 | 숨고 미열람 견적 환불 | 1:1 질문 48시간 무응답, 일반 질문 7일 무답변 시 원래 지갑으로 환불 |
| 1:1 지정 질문 | JustAnswer 전문가 매칭 | 특정 치료사 지정, 등급 비용 × 1.5 |
| 월 멤버십 | JustAnswer·쿠팡 와우 구독 | 매달 토큰 지급 + 질문 10~20% 할인, 자동 갱신 해지 |
| 현상금 추가 · 자동 채택 | 지식iN 내공 / Stack Overflow bounty | 현상금 추가 시 기한 연장, 기한 경과 시 추천순 자동 채택 |
| 감사 팁 | 토스·카카오 후원, 슈퍼챗 | 답변별 5/10/30 토큰 |
| 정산 대기 | 크몽 구매확정 후 정산 | 보상·팁 3일 대기 후 환전 가능 |
| 결제창 · 청약철회 | 국내 PG 결제창 | 카드·카카오페이·네이버페이·토스페이·휴대폰, 7일 내 미사용 충전분 결제 취소 |

## 실행

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # 프로덕션 빌드
```

## 구조

| 경로 | 설명 |
| --- | --- |
| `src/lib/config.ts` | **정책 값** — 보석 등급 조건, 질문 비용, 토큰 가격·패키지, 수수료, 환전 조건 |
| `src/lib/tier.ts` | 등급 판정 (조건 충족 여부, 다음 등급까지 부족한 조건) |
| `src/lib/ledger.ts` | **토큰 원장** — 충전·취소·멤버십·질문·현상금·채택·팁·환전·자동정산을 순수 함수로 구현. 서버 이전 시 그대로 DB 트랜잭션 안으로 옮기면 됨 |
| `src/lib/store.tsx` | 상태 보관(현재 localStorage 데모)과 화면 연결 |
| `src/components/Checkout.tsx` | 결제 시트 — 실서비스에서 PG 결제창 호출 지점 |
| `src/lib/seed.ts` | 데모 데이터 |
| `src/app/*` | 페이지 (홈, `/qa`, `/clinical`, `/therapists`, `/tiers`, `/wallet`, `/signup`) |

우측 상단 아바타 메뉴에서 데모 계정(환자/등급별 치료사)을 전환하고, "데모 초기화"로 데이터를 되돌릴 수 있습니다.

## 실서비스 전환 시 해야 할 일

1. **백엔드·DB** — `ledger.ts` 로직을 API 라우트 + DB(예: PostgreSQL/Supabase) 트랜잭션으로 옮기고, `sweep()`은 크론 작업으로 실행
2. **인증** — 카카오/네이버 소셜 로그인, 치료사 면허 진위 확인 및 경력·보수교육 증빙 심사
3. **결제** — PG 연동(토스페이먼츠, 포트원 등). 결제 승인 웹훅을 서버에서 검증한 뒤 토큰 지급, 멤버십은 빌링키 정기결제
4. **환전** — 본인 계좌 인증, 원천징수 신고, 지급 대행
5. **법률 검토** — 선불전자지급수단(전자금융거래법), 의료법(비대면 상담·의료광고 범위), 개인정보·민감정보 처리
