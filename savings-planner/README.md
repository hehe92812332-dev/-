# 모아플랜 (저축 플래너)

정해진 기간 안에 목표 금액을 모으는 계획을 짜 주고, 수입·지출 패턴을 분석해 항목별 지출 계획까지 정리해 주는 웹사이트입니다. 빌드 과정과 의존성 없이 HTML, CSS, JS만으로 동작합니다.

## 실행

```bash
cd savings-planner
npm start                  # http://localhost:5173
npm test                   # 단위 테스트 17개
npm run simulate           # 가상 사용자 10만 명 시뮬레이션 (현재 버전)
npm run simulate:compare   # v1 대비 비교 → docs/simulation-results.md
node scripts/build-single.js   # dist/moaplan.html : 파일 하나로 열리는 버전
```

`index.html`은 ES 모듈을 쓰므로 파일을 더블클릭해 열면 동작하지 않습니다. `npm start`로 띄우거나 `dist/moaplan.html`을 쓰세요. 정적 호스팅(Vercel, Netlify, GitHub Pages)에는 이 폴더를 그대로 올리면 됩니다.

## 기능

- **목표 설정**: 목표 금액, 지금 모아둔 돈, 기간(개월 수 또는 목표 날짜), 예·적금 이율, 비과세 여부
- **수입 분석**: 월 실수령액. 수입이 들쭉날쭉하면 최근 6개월로 변동 폭을 보고 보수적인 계획 기준을 정함
- **지출 패턴 분석**: 항목별 수입 대비 비중과 권장 비중 비교, 최근 3개월 추세(증가·감소), 변동 폭, 고정비·필수·선택 지출 구성
- **판정**: 여유 있음 / 빠듯함 / 지출 조정 / 기간 내 어려움 / 달성
- **지출 계획**: 항목별 권장 예산, 줄일 금액, 선택 지출 주간 한도, 목표 통장 자동이체 금액, 생활비 통장 여유분 (합계 = 수입)
- **대안**: 기간 연장, 목표 조정, 절충안, 필요한 추가 수입, 적자 해결 안내. 누르면 그 조건으로 다시 계산
- **월별 일정**: 통장 내역 형태로 회차별 입금, 세후 이자, 잔액, 25/50/75/100% 달성 시점, 그래프
- **중간 점검**: 지난 개월 수와 잔액을 넣으면 남은 기간에 맞춰 월 저축액을 다시 계산
- 입력값은 브라우저(localStorage)에만 저장되고 서버로 보내지 않음

## 구조

| 파일 | 역할 |
| --- | --- |
| `planner.js` | 계산 엔진 (브라우저·Node 공용): `buildPlan`, `replan`, `parseAmount` |
| `app.js`, `index.html`, `styles.css` | 화면 |
| `server.js` | 의존성 없는 로컬 정적 서버 |
| `simulation/population.js` | 가상 사용자 10만 명 생성 (시드 고정, 재현 가능) |
| `simulation/simulate.js` | 계획 → 기간 동안 생활 → 컴플레인 판정·집계 |
| `simulation/legacy/planner-v1.js` | 첫 구현 (비교 기준) |
| `docs/simulation-report.md` | 발견한 문제, 해결 방법, 남은 문제 |

## 계산 규칙 요약

- 월복리, 매월 말 납입, 이자소득세 15.4% (비과세 선택 시 제외)
- 월 저축액은 1,000원 단위로 올림
- 감축 한도: 고정비 0%, 필수 생활비 10%, 선택 지출 30%
- 안전 여유: 수입의 5% + 기억으로 적은 지출의 과소 추정분 + 줄이기로 한 금액의 40%
- 변동 소득: min(평균, 중앙값) − 0.75×표준편차, 최저 소득 이상
