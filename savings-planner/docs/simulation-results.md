# 저축 플래너 10만 명 시뮬레이션 리포트

- 가상 사용자: **100,000명** (시드 20261117, `npm run simulate:compare`로 재현)

- 계획을 받은 뒤 매달 적금 자동이체 → 소득 변동·실직·돌발 지출(월 5%)·지출 과소 보고·절약 피로를 반영해 기간 끝까지 생활합니다.
