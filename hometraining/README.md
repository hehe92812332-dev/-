# 한걸음 홈재활

뇌졸중 · 척수손상 · 파킨슨병 환자를 위한 기능 수준별 홈 트레이닝 웹사이트.
빌드 과정이 없는 정적 사이트입니다 (HTML · CSS · JS).

## 실행

```bash
cd hometraining
python3 -m http.server 8000   # http://localhost:8000
```

어떤 정적 호스팅(Vercel, Netlify, GitHub Pages, S3)에도 폴더째 올리면 됩니다.

## 구성

| 파일 | 내용 |
| --- | --- |
| `data.js` | 질환별 단계 · 운동(혼자/보호자 방법) · 운동량 · 주의사항 · 근거 문헌 22편 |
| `app.js` | 화면 그리기, 단계 찾기 질문, 혼자/보호자 전환, '오늘 했어요' 기록, 인쇄 |
| `styles.css` | 디자인 (기본 글자 18px, 글자 크게 보기 지원) |
| `sim/simulate-feedback.mjs` | 가상 사용자 30만 명 시뮬레이션 (실제 설문 아님) — 결과는 `docs/feedback-simulation.md` |

## 단계 기준

| 질환 | 기준 | 1단계 | 2단계 | 3단계 |
| --- | --- | --- | --- | --- |
| 뇌졸중 | FAC | 0–2 앉아서·누워서 | 3 잡고 서서 | 4–5 걸으면서 |
| 척수손상 | 손상 부위 · AIS | 경수(사지마비) | 흉·요수(하지마비) | 불완전 손상, 보행 가능 |
| 파킨슨병 | Hoehn & Yahr | 1–2 | 2.5–3 | 4 |

운동량은 AHA/ASA(2014, 2016), 국제 척수손상 운동 지침(Martin Ginis 2018),
APTA 파킨슨병 CPG(2022)·유럽 물리치료 지침(2014) 등의 범위 안에서 가정용으로 보수적으로 정했습니다.
문헌 목록은 사이트의 '근거 문헌' 화면과 `data.js`의 `REFS`에 있습니다.

## 내용 수정

운동을 고치거나 추가할 때는 `data.js`만 수정하면 됩니다.
혼자 하기 위험한 동작은 `alone: { safe: false, instead: "...", steps: [대체 동작] }` 형태로 적습니다.
