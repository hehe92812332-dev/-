# 가상 사용자 30만 명 시뮬레이션 — 피드백 반영 보고서

> **이 보고서는 실제 환자·보호자 설문이 아닙니다.**
> 가정한 사용자 분포로 30만 명의 가상 사용자(페르소나)를 만들고, 각 사용자가 사이트의 **실제 내용(data.js)과 기능(app.js)** 에서
> 막힐 지점을 규칙으로 센 결과입니다. 숫자는 아래 가정값에 따라 달라지며, 실제 사용성을 증명하지 않습니다.
> 실행: `node sim/simulate-feedback.mjs` (고정 시드라 결과가 매번 같습니다)

## 읽을 때 주의할 점

- 시뮬레이션은 **기능이 있으면 해결된 것으로** 셉니다. '수정 후 0%'는 그 문제를 다루는 기능이 생겼다는 뜻이지,
  모든 사용자가 실제로 잘 쓴다는 뜻이 아닙니다. 예를 들어 음성 합성은 기기에 한국어 음성이 없으면 동작하지 않습니다.
- 가장 큰 남은 문제는 **동작 그림·영상**입니다. 물리치료사가 직접 찍은 사진이나 짧은 영상으로 채우는 것을 권합니다.
  `data.js`의 운동에 `fig: "images/파일이름.jpg"`를 넣으면 화면에 나타납니다.

## 다음 단계 권고 — 실제 사용자 검증

1. 질환별 환자 5명 + 보호자 5명(총 30명)과 사용성 테스트: 단계 찾기 → 운동 1개 따라 하기 과제를 관찰
2. 사이트 안에 짧은 설문(이해도·안전감·지속 의향 5점 척도)을 넣어 실제 피드백 수집
3. 실제 응답이 모이면 이 시뮬레이션의 가정값을 실측값으로 바꿔 다시 실행
